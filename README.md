Sagistic is a gamified productivity bookmarklet that adds a floating quest manager to any webpage. Users can create, complete, delete, and prioritize tasks while earning XP and progressing through different RPG-style ranks. It also includes a Link Radar feature that scans webpages and highlights external links, internal links, email links, downloadable files, and page anchors using different colors.

Other features include four customizable themes, page-specific quests, a Carry and Drop system to transfer tasks between websites using the clipboard, automatic progress saving through localStorage, and keyboard shortcuts. The widget is draggable and uses Shadow DOM to keep its interface separate from the webpage.

I built Sagistic using vanilla JavaScript, HTML, and CSS. My goal was to combine productivity and gamification while creating a useful browser tool that works without requiring users to install an extension.
