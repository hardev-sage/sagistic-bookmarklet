Sagistic is a gamified productivity bookmarklet which adds the Floating Quest Manager to all web pages. With this extension, you can make, perform, delete, prioritize your tasks, get experience points and levels through the game like roles. Moreover, it has the Link Radar function which analyzes a web page for external links, internal links, emails, download links and anchors and marks them in various colors.

Other Sagistic features include four skins, site specific quests, Carry and Drop functions that enable you to move tasks across websites using clipboard, saving the progress to the localStorage and hotkeys. The bookmarklet is draggable and works with the Shadow DOM.

I have made the Sagistic using the JavaScript, HTML and CSS technologies. The goal of this project was to develop a gamified productivity tool that could be used from the browser without the need for installing any extension.
